# ADR-003: Выбор фронтенд-стека и сборщика для Web SPA

## Статус
Принято

## Контекст
Для веб-интерфейса TimeTracker (WebLab#8) требуется разработать одностраничное приложение (SPA), обеспечивающее удобный интерактивный секундомер, формы ручного ввода и визуализацию аналитики.

## Рассмотренные альтернативы
1. **Vanilla JavaScript / TypeScript (без фреймворка):**
   - *Плюсы:* Отсутствие сторонних зависимостей.
   - *Минусы:* Сложность поддержки реактивного состояния таймера и ручной манипуляции DOM.
2. **Vue.js:**
   - *Плюсы:* Простой порог входа, удобная реактивность.
   - *Минусы:* Меньшее распространение экосистемы кодогенерации типизированных клиентов по OpenAPI по сравнению с React.
3. **React + TypeScript + Vite (Выбранный вариант):**
   - *Плюсы:* Зрелая экосистема компонентов, строгая типизация TypeScript, быстрая сборка и HMR с Vite, простая генерация API-клиента из OpenAPI.
   - *Минусы:* Необходимость настройки стейт-менеджмента для сложных состояний.

## Решение
Использовать **TypeScript + React + Vite**.

## Последствия
- Высокая скорость разработки интерфейса.
- Компонентная структура с возможностью изолированного тестирования (Vitest).
